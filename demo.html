🏛️ Public Welfare Petition App

A comprehensive platform for citizens to report local civic issues and create petitions for public welfare.

🚀 Launch the App

📋 How to Use the Demo

  1. Registration: Fill in your details including Aadhaar number (use any 12-digit number for demo)
  2. Login: Use your Aadhaar number and any 6-digit OTP (e.g., 123456)
  3. Create Petition: Report an issue with photo and location
  4. Browse Petitions: View local petitions and support them
  5. Search: Find petitions by ID or keywords

🔐 User Authentication

Aadhaar-based registration and OTP verification system for secure user identification.

📱 Mobile Responsive

Beautiful design that works perfectly on all devices with touch-friendly interface.

📸 Camera Integration

Direct camera access to capture photos of issues with real-time preview.

🗺️ GPS Location

Automatic location detection or manual entry for precise issue reporting.

📋 Petition Management

Create, track, and manage petitions with unique IDs and status updates.

👥 Community Support

Support system where citizens can back petitions and track progress together.

🔍 Search & Discovery

Find petitions by ID or keywords, browse local issues in your area.

📊 Status Tracking

Real-time status updates: Pending, In Progress, and Resolved petitions.

🎯 Demo Features

  • Sample Data: Pre-loaded with 3 sample petitions to demonstrate functionality
  • Local Storage: Your data persists between sessions
  • Simulated Verification: Aadhaar verification is simulated for demo purposes
  • Responsive Design: Test on different screen sizes
  • Camera Access: Works on mobile devices with camera permission

Note: This is a frontend demo. In production, this would integrate with real backend services for Aadhaar verification, SMS OTP, and data persistence.
